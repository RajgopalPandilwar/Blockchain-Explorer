# Ethereum Blockchain Explorer

A web-based Ethereum blockchain explorer that allows users to browse blocks, transactions, and addresses on the Ethereum network.

## Features

- Browse latest blocks on the Ethereum blockchain
- View detailed transaction information
- Search for specific blocks, transactions, or addresses
- Real-time network statistics

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Blockchain Interaction:** Web3.js / Ethers.js
- **API:** Etherscan API / Infura

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
git clone https://github.com/RajgopalPandilwar/Blockchain-Explorer.git
cd Blockchain-Explorer
npm install
npm start
```

### Usage

1. Start the application with `npm start`
2. Open your browser and navigate to `http://localhost:3000`
3. Use the search bar to look up blocks, transactions, or addresses
4. Browse the latest blocks on the Ethereum mainnet
